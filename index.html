Chirolas App: punto de venta para kioscos y minimarkets

Un producto SaaS que diseñé y desarrollé de punta a punta: backend, frontend, cobros, infraestructura y la landing comercial.

Visitar sitio Instagram

El problema

Los kioscos y minimarkets suelen vender con cuaderno o con sistemas caros y complejos. Pierden control de caja, de stock y no saben qué productos les dejan plata.

La solución

Un POS rápido para el mostrador, con cobro por QR y Point de Mercado Pago, apertura y cierre de caja con arqueo, control de stock, historial y estadísticas de ventas.

El modelo

SaaS por suscripción con planes pagos, multi-local y multi-usuario con roles, y una landing propia para captar comercios.

Decisiones técnicas

  • Multi-tenant seguro: Spring Security + JWT con aislamiento de datos por comercio, cubierto con tests.
  • Cobros integrados: QR y Point de Mercado Pago con webhooks, y suscripciones recurrentes.
  • Tiempo real: Server-Sent Events para reflejar pagos y ventas al instante en el mostrador.
  • Funciona offline: PWA con service worker para seguir vendiendo aunque se corte internet.
  • Datos confiables: PostgreSQL en Supabase con migraciones versionadas (Flyway) y backups automáticos con GitHub Actions.
  • Rendimiento y protección: caché con Caffeine y rate limiting con Bucket4j.
